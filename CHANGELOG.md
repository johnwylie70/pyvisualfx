# Changes

## 0.0.0 (not released)

The first version: the effects of vfx.js for a Pyctures scene, in Python's spelling. Every effect, look and palette of the JavaScript library; settings as attributes; `react` and `listen_to` for music; `shader`; one command an effect and one a changed setting, with the effects run once for each frame Python sends, on Python's clock.
